2. Calculating the shortest path between the source and destination.
CODE:
path = nx.shortest_path(G, source = "Hannah", target = "Frank")

3. Calculating the network density. Density: D = 2E/N(N-1).
CODE:
density = nx.density(G)
print("Network Density : ", round(density, 2))

4. Ego Networks.
CODE:
